# 🚗 Car Scroll Animation

A scroll-driven hero section animation built as part of the Itzfizz Web Development Internship assignment.

## 🌐 Live Demo

https://adityaafil.github.io/Car-Scroll-Animation/

## 📂 GitHub Repository

https://github.com/AdityaAfil/Car-Scroll-Animation

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- React.js
- Tailwind CSS
- GSAP
- Lenis

## ✨ Features

- Scroll-driven car animation
- Smooth scrolling
- GSAP-powered animations
- Responsive hero section
- Animated statistics
- Smooth intro animation
- Scroll-based text and card reveals
- Responsive design

## 🎯 Project Objective

The project recreates a scroll-driven hero section with smooth animations and interactions, focusing on motion quality, performance, and responsive behavior.
